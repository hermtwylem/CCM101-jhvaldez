# Automation Research: The Language of Automation

## 1. Bash Script

A Bash script is a file that contains Linux commands that run together to perform a task. The line `#!/bin/bash` is called the shebang, and it tells Linux to use Bash to execute the script.

## 2. Variables

Variables store information such as folder names, file paths, and timestamps. Using variables like `$BACKUP_DIR` makes a script easier to update because you can change the value in one place instead of changing it throughout the code.

## 3. Cron Job

A Cron job is a scheduled task in Linux that runs automatically at a specific time or date. It is useful in cloud operations because it can automate regular tasks such as backups, system maintenance, and log cleanup without requiring someone to run commands manually.
