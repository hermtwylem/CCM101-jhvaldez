# Laboratory 05 – Cloud Data Engineer

## Mission Overview

In this laboratory activity, I learned about cloud storage and the three main types of storage: Block Storage, File Storage, and Object Storage. I also deployed a MinIO server using Docker in the KillerCoda Playground.

The main goal of this activity was to create an S3-compatible object storage server, create a bucket named `client-photos`, and upload a sample file.

## Objectives

* Understand the differences between Block, File, and Object Storage.
* Deploy an S3-compatible MinIO server using Docker.
* Access the MinIO Web Console using port forwarding.
* Create a cloud storage bucket.
* Upload a file to the bucket.
* Document the deployment process using Markdown.
* Practice using Docker and Linux commands.

## Tools Used

* KillerCoda Playground
* Ubuntu Linux
* Docker
* MinIO
* GitHub
* Web Browser
* Markdown

## Skills Learned

* Understanding different types of cloud storage.
* Running Docker containers.
* Deploying MinIO as an object storage server.
* Using Linux commands to check containers.
* Accessing a web service through a forwarded port.
* Creating buckets and uploading objects.
* Writing technical documentation in Markdown.
