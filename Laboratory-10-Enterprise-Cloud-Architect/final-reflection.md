
# Mission 10: Final Journey Reflection – The Enterprise Cloud Architect

Throughout CCM101 – Cloud Computing, we gained different skills and knowledge from Mission 1 to Mission 10. We began by learning how to install and manage Ubuntu Server through VirtualBox, use Linux commands, manage user accounts, and connect through SSH. We also studied cloud networking, port forwarding, and public cloud services. As we continued, we learned how to use Docker, container images, volumes, and Docker Compose to deploy and manage applications. These activities helped us understand the basic concepts of cloud computing and server management.

In Mission 10, we used our knowledge to deploy a WordPress website and MariaDB database on an Ubuntu Server virtual machine. We used Docker Compose to manage the containers and persistent volumes to protect our stored data. We also configured the UFW firewall to allow only the required connections, including SSH through port 22 and web access through port 8080, while keeping the database private. In addition, we created a Bash script for backing up the database and WordPress files and scheduled it to run daily using Cron. We experienced some difficulties with network connections, port configuration, and database backups, but these challenges helped us develop our troubleshooting skills.

In conclusion, Mission 10 showed us that cloud computing involves more than just running applications on a server. It also requires proper security, system maintenance, data protection, and automation. Completing all ten missions gave us practical experience that we can apply to future IT projects. It also helped us prepare for possible careers in cloud computing, DevOps, and infrastructure management. Overall, this experience taught us to be patient, solve problems carefully, and continue learning as technology develops.
